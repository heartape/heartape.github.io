# 2.c++基本组件

# 1.Actor

Actor游戏世界里的“实体”，任何能放进场景里的东西：

  • 玩家
  • 敌人
  • 灯光
  • 摄像机
  • 子弹
  • 门
  • 特效

本质都是 Actor。

Actor 生命周期:

Constructor
BeginPlay
Tick
EndPlay
Destroy

 └── MovementComponent

Component 作用
UCameraComponent 摄像机
USkeletalMeshComponent 骨骼

UNiagaraComponent 粒子

# 3.Character

Character是专门用于“人形角色”的 Pawn

# 4.Controller

Controller的作用是“谁在控制 Pawn”，其意义在于“控制逻辑与角色实体分离”，这样角色可以被不同控制器接管

# 5.GameMode

GameMode是整个游戏的规则管理器 负责：

  • 玩家出生
  • 默认 Pawn
  • 游戏规则
  • 胜负条件
  • Match状态

GameMode 管理

DefaultPawnClass
PlayerControllerClass
HUDClass
GameStateClass
